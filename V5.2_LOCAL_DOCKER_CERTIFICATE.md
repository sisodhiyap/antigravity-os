## 🔒 Security & Cryptographic Specifications

- **Password Hashing**: PBKDF2-SHA512 with 100,000 iterations and a 32-byte cryptographic salt generated via `crypto.randomBytes(32)`.
- **Timing-Safe Verification**: Constant-time verification using `crypto.timingSafeEqual` prevents side-channel timing attacks.
- **Brute-Force Protection**: 5-trial sliding window with automatic 900-second lockout.
- **Session Security**: High-entropy HttpOnly session tokens with session rotation on login and complete invalidation on logout.
- **Client Bundle Audit**: Zero secrets or live API keys exposed in compiled Next.js client bundles (`.next/static`).
- **Sandbox Isolation**: Path traversal (`../../`) blocked, dangerous commands (`rm -rf /`) blocked, and unsafe `eval()` strictly disallowed.
