## 1. Sandboxed Self-Healing Loop

When a defect or failure occurs during autonomous execution:

```text
       FAILURE DETECTED
              ↓
  CREATE REPAIR CHECKPOINT
              ↓
   ROOT CAUSE LOCALIZATION
              ↓
GENERATE CANDIDATES (A, B, C)
              ↓
    TEST IN ISOLATED SANDBOX
              ↓
     REGRESSION & SECURITY
              ↓
    ZERO-TRUST REALITY PROOF
              ↓
   SELECT BEST VERIFIED REPAIR
```

If all candidates fail:
$$\text{ROLLBACK} \longrightarrow \text{VERIFY: RESTORED\_HASH == CHECKPOINT\_HASH}$$

No repair is ever promoted to production without passing full regression, security, and reality proofs.
