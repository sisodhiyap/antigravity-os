## 1. Workflow Architecture

All workflows are declared with structured metadata:
- `workflowId`: Unique identifier
- `modality`: IMAGE, VIDEO, AUDIO, 3D, UPSCALE, CINEMATIC
- `requiredModels`: Explicit model dependency list
- `requiredNodes`: Custom / core node dependencies
- `requiredVramMb`: Minimum VRAM threshold
- `inputs`: Typed input parameter schema
- `outputs`: Formats produced (e.g. `image/png`, `video/mp4`, `model/gltf-binary`)
- `hash`: SHA-256 integrity hash
- `verified`: Boolean reality verification tag

## 2. Dynamic Workflow Sandboxing

Workflows auto-generated by Hermes are quarantined inside sandboxes and verified through schema validation, node sanitization, and output reality checks before promotion to the library.
