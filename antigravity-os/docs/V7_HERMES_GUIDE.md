# Antigravity OS V7.0 — Hermes Autonomous Agent Guide

## 1. Hermes Agent Overview
Hermes is the task planning and execution agent in Antigravity OS:
- **DAG Task Decomposition**: Decomposes high-level user objectives into acyclic dependency graphs.
- **Sandboxed Execution**: Runs tasks in isolated workspaces with per-task resource and token budgets.
- **Autonomy Levels (1–5)**:
  - Level 1: Read-Only inspection
  - Level 2: Sandbox write & execution
  - Level 3: Project-wide refactoring
  - Level 4: Automated CI/CD execution
  - Level 5: Production mutation (Requires Owner Signature)
