# ANTIGRAVITY AI ROUTER SECURITY POLICY

## 1. Local-Only Binding
All services, HTTP listeners, API gateways, and dashboard interfaces bind strictly to `127.0.0.1` (localhost). External network binding is disabled by default.

## 2. Zero ToS Circumvention & Credential Safety
- No account sharing, cookie hijacking, or rate-limit circumvention.
- API keys are read strictly from local environment variables or standard user configurations.
- All authorization headers and secret tokens are sanitized and redacted from logs, telemetry, and dashboard screens.

## 3. Local Model Privacy
- Tasks processed via local Ollama models (`qwen2.5-coder:14b`, `deepseek-r1:7b`) remain 100% local on the developer machine and are never transmitted over the internet.

## 4. Command Execution Safety
- Destructive commands or unverified shell execution generated by LLMs are sanitized and require explicit user/agent permission before running.
